本示例使用到的资源：
TIM1 BRK1    --   PB4
TIM1 CH1     --   PA0
TIM1 CH1N    --   PB3
TIM1 CH2     --   PA1
TIM1 CH2N    --   PA4
TIM1 CH3     --   PB2
TIM1 CH3N    --   PB5


本示例的功能流程：
1、上电配置时钟（RCH 48MHz）；
2、配置TIM1为PWM模式输出（3个通道）;
       通道1输出参数：CC1P高有效，CC1NP高有效，
                      通道1输出空闲电平为高有效，互补通道1输出空闲电平为低有效；
       通道2输出参数CC2P高有效，CC2NP高有效，
                      通道2输出空闲电平为高有效，互补通道2输出空闲电平为低有效；
       通道3输出参数：CC3P高有效，CC3NP高有效，
                      通道3输出空闲电平为高有效，互补通道3输出空闲电平为低有效；
   
3、其中通道1输出波形的占空比为：50%
       通道2输出波形的占空比为：37.5%
       通道3输出波形的占空比为：25%

4、配置断路输入信号上升沿有效时，触发断路事件，此时无PWM输出；

注意：
1、断路输入信号上电默认状态为低电平；
2、当断路输入信号上升沿有效时，触发断路后的输出为（仅以通道1为例）：
                              __________________________
                             | 
 BRK1 _______________________|

                              <->

        |       |        |       |                 
        |_______|        |_______|                                
          _____            __ <-> <--------------->               
         |     |          |  |     空闲状态
 CH1N ___|     |__________|  |___________________________

本示例使用到的资源：
USER_BUTTON    -----   PB2

本示例的功能流程：
1、上电配置系统时钟源为RCH（48MHz）；
2、USER按键初始化；
3、等待用户按下USER按键；
4、进入Flash选项字节更新流程：
   - 判断是否需要更新选项字节，若选项字节无需更新直接退出流程；
   - 解锁Flash和选项字节；
   - 选项字节擦除及编程：更新NRST引脚复位释放后切换成GPIO，更新IWDG在Stop/Deepstop下停止计数，其余选项字节为出厂默认值；
   - 若更新流程异常会重复3次，仍异常会进入异常处理分支。
注意：若用户需要对选项字节进行加载，需要执行复位加载选项字节。

本示例使用到的资源：
USER BUTTON  --   PB2
ADC_IN4      --   PA7
ADC_IN8      --   内部BGR通道
UART TX      --   PA3  
UART RX      --   PA4 


本示例的功能流程：
1、上电配置系统时钟为RCH 48MHz；
2、按键配置为EXTI模式，下降沿生成中断；
3、初始化UART,波特率115200
4、初始化PA7，ADC采集此引脚电压；
5、初始化ADC：
     1）3分频，采样时间239adc_clk；
     2）使能wait模式; 
     3）转换通道选择通道4和VBGR；
     4）软件触发，单次扫描转换模式；
6、ADC校准，提升校准系数的精度；
7、等待3s；
8、禁止ADC和VBGR,进入deepstop模式（WFI）; 当按键按下时，生成EXTI中断，唤醒CPU，恢复系统时钟配置;
9、使能VBGR通道，启动ADC转换，查询模式；
10、等待转换完成，读取ADC转换数据;
11、重复上述步骤9，依次读取每个通道ADC转换数据，每个通道读取10次并求和取平均;
12、使用VBGR平均采样值校准ADC当前的参考电压，并将外部通道采样平均值转换成电压值，通过串口打印输出;

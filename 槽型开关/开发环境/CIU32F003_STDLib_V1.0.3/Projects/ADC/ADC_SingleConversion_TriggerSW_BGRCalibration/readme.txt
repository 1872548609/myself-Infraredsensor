本示例使用的资源：
ADC_IN8      --   内部BGR通道


本示例的功能实现流程：
通过查询的方式获取ADC内部通道BGR的采样值，根据出厂校准值，对参考电压进行校准。
1、上电配置系统时钟为RCH 48MHz；
2、初始化内部通道VBGR；
3、初始化ADC：
     1）3分频，采样时间239adc_clk；
     2）使能wait模式; 
     3）转换通道选择通道8； 
     4）软件触发，单次扫描转换模式；
4、ADC校准，提升校准系数的精度；
5、启动ADC转换，查询模式；
6、等待转换完成;
7、读取ADC转换数据;
8、重复上述步骤5-7，依次读取10次ADC转换数据并求和取平均;
9、将平均值校准参考电压值；

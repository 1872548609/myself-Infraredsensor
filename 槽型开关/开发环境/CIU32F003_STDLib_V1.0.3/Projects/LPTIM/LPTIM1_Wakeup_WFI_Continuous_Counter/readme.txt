本示例使用到的资源：
LED         -----   PB1


本示例的功能流程：
1、上电配置系统时钟（RCH作为时钟源）48M；
2、初始化SYSTICK；
3、初始化LED的GPIO，LED默认熄灭；
4、初始化EXTI使能LPTIM1的中断唤醒低功耗；
5、初始化LPTIM1：工作时钟选择RCL，设置计数时钟不分频；
6、使能LPTIM1的NVIC中断；
7、延时3S；
10、使能LPTIM1的自动重载匹配中断，使能LPTIM1，写入自动重装载值(0x7CFF)，
    启动连续计数，将每1s产生一次自动重载匹配中断，在中断服务程序中翻转LED；
11、进入while循环体：控制MCU进入低功耗模式Deepstop。
